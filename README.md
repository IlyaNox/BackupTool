# BackupTool

Простой bash-скрипт для резервного копирования директории в `.tar.gz` архив.

## Использование

```bash
./backup.sh [source_dir] [backup_dir]
```

- `source_dir` — папка, которую нужно забэкапить (по умолчанию `/home/$USER/Documents`)
- `backup_dir` — куда сохранять архивы (по умолчанию `/home/$USER/Backups`)

Пример:

```bash
./backup.sh ~/Projects ~/Backups
```

## Что делает скрипт

- Создаёт архив вида `backup_ГГГГ-ММ-ДД_ЧЧ-ММ-СС.tar.gz`
- Проверяет, что исходная папка существует
- Автоматически удаляет архивы старше 7 дней

## Требования

- bash
- tar
